# PRD 51 — AGENTS.md Auto-Loading

## Status: Draft
## Depends on: PRD 41 (`/init` command), PRD 26 (conversation persistence), PRD 32a–32e (slash commands)

---

## 1. Problem

xaft agents start every session without any project-specific knowledge.
The planner agent must rediscover the codebase conventions, forbidden
patterns, test commands, and architecture notes from scratch on every run —
wasting LLM turns and making responses less consistent.

`AGENTS.md` is the intended solution: a human-authored project memory file
that agents read at session start. As of today it is never loaded
automatically. The `/init` command exists only as a stub (`/init: not yet
connected to runtime.`).

Without auto-loading, AGENTS.md provides zero value even when it exists.
Users who took the time to write one are confused when the agent ignores it.

---

## 2. Goals

1. xaft automatically discovers and reads `AGENTS.md` from the working
   directory (PWD) at session start — BEFORE the first agent turn.
2. The file content is injected as a `Message::system(...)` at the front of
   `request.prior_messages` so every agent in the Planner → Coder →
   QA ↔ Fixer pipeline receives it as permanent context.
3. When the agent calls `list_files` and the returned file list includes one
   or more paths ending with `AGENTS.md`, each such file is auto-read and
   injected as a `Message::user(...)` annotated with metadata key
   `"source": "agents_md_auto_load"`, giving the agent fresh context
   mid-conversation (handles per-subdirectory AGENTS.md files).
4. Multiple AGENTS.md files (e.g., root `AGENTS.md` and
   `backend/AGENTS.md`) are all loaded, root first.
5. AGENTS.md files larger than 64 KB are truncated with a
   `[AGENTS.md truncated at 64 KB]` notice appended to the content.
6. The `/init` slash command is fully implemented: it generates a starter
   `AGENTS.md` at the project root with a template that covers project
   summary, tech stack, conventions, forbidden actions, testing
   instructions, and common patterns.
7. A new `XaftAgentsMdLoaded` signal is emitted when any AGENTS.md is
   loaded, visible in the TUI as a brief status line.

---

## 3. Non-Goals

- Hot-reloading AGENTS.md while the agent is running (file-system watching).
- AGENTS.md content generated by the LLM during `/init` (heuristic
  detection only for `/init`; PRD 41 covers that separately).
- Merging AGENTS.md content with CLAUDE.md or other project docs.
- Enforcing a schema on AGENTS.md (free-form markdown is allowed).
- Loading AGENTS.md from remote sources (URLs, git remotes).
- `agents_md_enabled = false` causing silent ignoring when the file exists;
  a warning must be shown.

---

## 4. Architecture

### 4.1 Overview

```text
XaftRuntime::run_task()
    ├── … session setup, provider, tools …
    ├── [NEW] AgentsMdLoader::load(working_dir, &config.core)
    │         ├── look for AGENTS.md at working_dir/AGENTS.md
    │         ├── if found: read, truncate if > max_bytes, prepend to prior_messages
    │         └── emit XaftAgentsMdLoaded signal
    ├── run_workflow(task, …, prior_messages)
    │         ├── HandoffOrchestrator
    │         │     └── ListFilesTool call →
    │         │           AgentsMdPostHook::after()
    │         │               ├── detect any path ending with AGENTS.md
    │         │               ├── read those files via FsWorkspaceStore
    │         │               └── queue Message::user(content, metadata)
    │         │                     injected before next LLM turn
    │         └── … normal pipeline …
    └── RunResult
```

The loader runs synchronously in `run_task()` before `run_workflow()`.
The hook runs asynchronously as a `ToolHook` registered globally on the
`HandoffOrchestrator`.

### 4.2 New file: `crates/xaft-runtime/src/agents_md.rs`

```rust
//! AGENTS.md auto-loading for xaft sessions.
//!
//! Discovers and injects `AGENTS.md` files from the workspace root and
//! any subdirectories returned by `list_files` during agent execution.

use std::path::{Path, PathBuf};
use std::sync::{Arc, Mutex};

use agtrs_runtime::transport::Message;
use agtrs_runtime::signals::SignalBus;
use tracing::{debug, info, warn};

use xaft_config::CoreConfig;

/// Maximum byte size before AGENTS.md is truncated (configurable via config).
pub const DEFAULT_MAX_BYTES: usize = 65_536; // 64 KiB

/// Suffix appended when a file is truncated.
pub const TRUNCATION_NOTICE: &str = "\n\n[AGENTS.md truncated at 64 KB]";

/// File name recognised as the project memory file.
pub const AGENTS_MD_FILENAME: &str = "AGENTS.md";

// ── AgentsMdLoader ────────────────────────────────────────────────────────────

/// Loads and injects AGENTS.md files into the conversation context.
///
/// Used in two phases:
/// 1. **Session start** — `load_for_session()` reads `AGENTS.md` from the
///    workspace root and prepends a `Message::system` to `prior_messages`.
/// 2. **Mid-session** — `AgentsMdPostHook` (a `ToolHook`) calls
///    `load_from_paths()` after a `list_files` call that returned paths
///    containing `AGENTS.md`, injecting `Message::user` blocks.
#[derive(Debug)]
pub struct AgentsMdLoader {
    working_dir: PathBuf,
    max_bytes: usize,
    signals: Arc<SignalBus>,
}

impl AgentsMdLoader {
    /// Create a new loader for `working_dir`.
    pub fn new(
        working_dir: impl Into<PathBuf>,
        max_bytes: usize,
        signals: Arc<SignalBus>,
    ) -> Self {
        Self {
            working_dir: working_dir.into(),
            max_bytes,
            signals,
        }
    }

    /// Load `AGENTS.md` from the workspace root, returning a system message
    /// to prepend to `prior_messages`, or `None` if no file was found.
    ///
    /// Called once in `XaftRuntime::run_task()` before `run_workflow()`.
    pub async fn load_for_session(&self) -> Option<Message> {
        let path = self.working_dir.join(AGENTS_MD_FILENAME);
        if !path.exists() {
            debug!(path = %path.display(), "agents_md: no AGENTS.md at workspace root");
            return None;
        }

        let (content, byte_size) = match self.read_truncated(&path).await {
            Ok(pair) => pair,
            Err(e) => {
                warn!(path = %path.display(), error = %e, "agents_md: failed to read");
                return None;
            }
        };

        info!(
            path = %path.display(),
            bytes = byte_size,
            "agents_md: loaded AGENTS.md for session"
        );

        let text = format!(
            "## Project Context (from AGENTS.md)\n\n{content}"
        );

        // Emit signal before returning
        let signals = Arc::clone(&self.signals);
        let rel_path = AGENTS_MD_FILENAME.to_string();
        tokio::spawn(async move {
            signals
                .emit(XaftAgentsMdLoaded {
                    paths: vec![rel_path],
                    total_bytes: byte_size,
                })
                .await;
        });

        Some(Message::system(text))
    }

    /// Read a set of relative AGENTS.md paths (returned by `list_files`),
    /// returning a `Message::user` for each file found, root-first.
    ///
    /// Called from `AgentsMdPostHook::after()` mid-conversation.
    pub async fn load_from_paths(
        &self,
        relative_paths: Vec<String>,
    ) -> Vec<Message> {
        let mut messages = Vec::new();
        let mut loaded_paths = Vec::new();
        let mut total_bytes = 0usize;

        // Sort: root-level files first (fewer path segments first)
        let mut sorted = relative_paths;
        sorted.sort_by_key(|p| p.matches('/').count());

        for rel in &sorted {
            let abs = self.working_dir.join(rel);
            match self.read_truncated(&abs).await {
                Ok((content, size)) => {
                    let text = format!(
                        "[Auto-loaded {rel}]\n\n{content}"
                    );
                    let mut msg = Message::user(text);
                    // Annotate with metadata for downstream consumers
                    msg = msg.with_metadata("source", "agents_md_auto_load");
                    msg = msg.with_metadata("path", rel.clone());
                    messages.push(msg);
                    loaded_paths.push(rel.clone());
                    total_bytes += size;
                }
                Err(e) => {
                    warn!(path = %rel, error = %e, "agents_md: mid-session load failed");
                }
            }
        }

        if !loaded_paths.is_empty() {
            let signals = Arc::clone(&self.signals);
            tokio::spawn(async move {
                signals
                    .emit(XaftAgentsMdLoaded {
                        paths: loaded_paths,
                        total_bytes,
                    })
                    .await;
            });
        }

        messages
    }

    /// Read a file, truncating to `max_bytes` if necessary.
    ///
    /// Returns `(content, actual_bytes_read)`.
    async fn read_truncated(&self, path: &Path) -> std::io::Result<(String, usize)> {
        let bytes = tokio::fs::read(path).await?;
        let original_len = bytes.len();
        let (truncated, content) = if original_len > self.max_bytes {
            let slice = &bytes[..self.max_bytes];
            // Find the last valid UTF-8 boundary within the slice
            let valid_end = find_utf8_boundary(slice);
            let mut text = String::from_utf8_lossy(&bytes[..valid_end]).into_owned();
            text.push_str(TRUNCATION_NOTICE);
            (true, text)
        } else {
            let text = String::from_utf8_lossy(&bytes).into_owned();
            (false, text)
        };

        if truncated {
            warn!(
                path = %path.display(),
                original_bytes = original_len,
                limit = self.max_bytes,
                "agents_md: file truncated at max_bytes limit"
            );
        }

        Ok((content, original_len.min(self.max_bytes)))
    }
}

/// Find the largest byte index ≤ `limit` that is a valid UTF-8 boundary.
fn find_utf8_boundary(bytes: &[u8]) -> usize {
    let mut end = bytes.len();
    while end > 0 && (bytes[end - 1] & 0xC0) == 0x80 {
        end -= 1;
    }
    end
}
```

### 4.3 New struct: `AgentsMdPostHook`

The post-hook intercepts `list_files` results and triggers auto-read of
any AGENTS.md paths that appear in the output.

```rust
//! Tool hook that watches `list_files` output for AGENTS.md paths
//! and injects their content into the next LLM turn.

use std::sync::Arc;
use async_trait::async_trait;

use agtrs_runtime::error::AgtrsError;
use agtrs_runtime::tool_hooks::{
    AfterHookDecision, BeforeHookDecision, ToolAfterContext,
    ToolCallContext, ToolExecutionStatus, ToolHook,
};
use agtrs_runtime::transport::Message;

use super::AgentsMdLoader;

/// Hook that fires after every `list_files` call.
///
/// When the tool output contains paths ending with `AGENTS.md`, each such
/// file is read and the content is prepended to the LLM conversation as a
/// `Message::user(...)` block with `"source": "agents_md_auto_load"` metadata.
///
/// The hook is stateless: every qualifying `list_files` result triggers a
/// fresh load. Content de-duplication is handled by the orchestrator's
/// conversation window — repeated AGENTS.md content costs a small amount of
/// context but ensures the agent always has fresh project memory.
pub struct AgentsMdPostHook {
    loader: Arc<AgentsMdLoader>,
    /// Pending messages to inject before the next LLM turn.
    pending: Arc<tokio::sync::Mutex<Vec<Message>>>,
}

impl AgentsMdPostHook {
    pub fn new(loader: Arc<AgentsMdLoader>) -> Self {
        Self {
            loader,
            pending: Arc::new(tokio::sync::Mutex::new(Vec::new())),
        }
    }

    /// Drain any queued messages (called by the orchestrator before each LLM turn).
    pub async fn drain_pending(&self) -> Vec<Message> {
        self.pending.lock().await.drain(..).collect()
    }
}

#[async_trait]
impl ToolHook for AgentsMdPostHook {
    async fn before(
        &self,
        _context: &ToolCallContext,
    ) -> Result<BeforeHookDecision, AgtrsError> {
        Ok(BeforeHookDecision::Proceed { modified_input: None })
    }

    async fn after(
        &self,
        context: &ToolAfterContext,
    ) -> Result<AfterHookDecision, AgtrsError> {
        if context.call.tool_name != "list_files" {
            return Ok(AfterHookDecision::Return { modified_result: None });
        }

        let ToolExecutionStatus::Success(ref result) = context.result else {
            return Ok(AfterHookDecision::Return { modified_result: None });
        };

        // Scan the plain-text output for lines ending with AGENTS.md
        let agents_md_paths: Vec<String> = result
            .content
            .lines()
            .filter(|line| {
                let trimmed = line.trim();
                trimmed == "AGENTS.md"
                    || trimmed.ends_with("/AGENTS.md")
            })
            .map(|line| line.trim().to_string())
            .collect();

        if agents_md_paths.is_empty() {
            return Ok(AfterHookDecision::Return { modified_result: None });
        }

        // Load all detected AGENTS.md paths
        let messages = self.loader.load_from_paths(agents_md_paths).await;
        if !messages.is_empty() {
            self.pending.lock().await.extend(messages);
        }

        Ok(AfterHookDecision::Return { modified_result: None })
    }
}
```

```rust
// ── AGENTS.md auto-load (PRD 51) ──────────────────────────────────────────
if self.config.core.agents_md_enabled {
    let loader = AgentsMdLoader::new(
        working_dir,
        self.config.core.agents_md_max_bytes,
        Arc::clone(&self.signals),
    );
    if let Some(system_msg) = loader.load_for_session().await {
        // Prepend: system context must come before any prior_messages
        let mut new_prior = vec![system_msg];
        new_prior.extend(request.prior_messages.drain(..));
        request.prior_messages = new_prior;

    // Install the post-hook for mid-session AGENTS.md discovery
    let agents_md_hook = Arc::new(AgentsMdPostHook::new(Arc::new(loader)))
        as Arc<dyn agtrs_runtime::tool_hooks::ToolHook>;

    // via a new `extra_hooks: Vec<Arc<dyn ToolHook>>` parameter (see §4.7).
}
```

### 4.7 Passing the hook to `run_workflow()`

`run_workflow()` in `crates/xaft-runtime/src/orchestrator.rs` currently
accepts a single `ReadBeforeEditHook`. Extend its signature to accept a
`Vec<Arc<dyn ToolHook>>` and register all hooks as global hooks on the
`HandoffOrchestrator`:

```rust
pub async fn run_workflow(
    task: &str,
    // … existing parameters …
    extra_hooks: Vec<Arc<dyn agtrs_runtime::tool_hooks::ToolHook>>,
) -> Result<(String, ExitCode), RuntimeError> {
    // …
    let read_before_edit_hook = Arc::new(xaft_tools::ReadBeforeEditHook::new())
        as Arc<dyn agtrs_runtime::tool_hooks::ToolHook>;

    let mut builder = HandoffOrchestrator::builder()
        // …
        .with_global_tool_hook(read_before_edit_hook);

    for hook in extra_hooks {
        builder = builder.with_global_tool_hook(hook);
    }

    let orchestrator = builder.build();
    // …
}
```

### 4.8 `/init` command implementation

Implement `InitHandler` in `crates/xaft-tui/src/slash/commands/init.rs`:

```rust
use std::path::PathBuf;
use tokio::fs;

use crate::slash::registry::SlashHandler;
use crate::slash::{CommandContext, CommandResult};

pub struct InitHandler;

impl SlashHandler for InitHandler {
    fn description(&self) -> &'static str {
        "Generate AGENTS.md project memory file"
    }

    fn args_hint(&self) -> Option<&'static str> {
        Some("[--force]")
    }

    fn is_async(&self) -> bool {
        true
    }

    fn execute(&self, _ctx: CommandContext) -> CommandResult {
        CommandResult::Error("use async execute".into())
    }

    fn execute_boxed_async(
        &self,
        ctx: CommandContext,
    ) -> std::pin::Pin<Box<dyn std::future::Future<Output = CommandResult> + Send + 'static>> {
        Box::pin(async move {
            let working_dir = ctx
                .working_dir
                .as_deref()
                .map(PathBuf::from)
                .unwrap_or_else(|| std::env::current_dir().unwrap_or_default());

            let force = ctx.args.as_deref() == Some("--force");
            let agents_md_path = working_dir.join("AGENTS.md");

            // Check for existing file
            if agents_md_path.exists() && !force {
                return CommandResult::Lines(vec![
                    "  AGENTS.md already exists in this directory.".into(),
                    "  Use /init --force to overwrite, or edit the existing file.".into(),
                ]);
            }

            // Detect project type
            let project_info = detect_project(&working_dir).await;
            let content = render_agents_md_template(&project_info, &working_dir);

            match fs::write(&agents_md_path, &content).await {
                Ok(_) => {
                    let byte_size = content.len();
                    CommandResult::Lines(vec![
                        format!(
                            "  Generated AGENTS.md ({byte_size} bytes)"
                        ),
                        format!(
                            "  Detected: {}",
                            project_info.language_summary
                        ),
                        format!(
                            "  Build:    {}",
                            project_info.build_cmd.as_deref().unwrap_or("(unknown)")
                        ),
                        format!(
                            "  Test:     {}",
                            project_info.test_cmd.as_deref().unwrap_or("(unknown)")
                        ),
                        "  Edit AGENTS.md to add project-specific conventions.".into(),
                    ])
                }
                Err(e) => CommandResult::Error(format!("Failed to write AGENTS.md: {e}")),
            }
        })
    }
}

struct ProjectInfo {
    name: String,
    language_summary: String,
    build_cmd: Option<String>,
    test_cmd: Option<String>,
    top_level_dirs: Vec<String>,
}

async fn detect_project(dir: &std::path::Path) -> ProjectInfo {
    // Priority order: Cargo.toml → package.json → pyproject.toml → go.mod → dir name
    if dir.join("Cargo.toml").exists() {
        let name = parse_cargo_name(dir).await
            .unwrap_or_else(|| dir_name(dir));
        return ProjectInfo {
            name,
            language_summary: "Rust / Cargo".into(),
            build_cmd: Some("cargo build --release".into()),
            test_cmd: Some("cargo test --workspace".into()),
            top_level_dirs: scan_top_dirs(dir).await,
        };
    }
    if dir.join("package.json").exists() {
        let name = dir_name(dir);
        let (build, test) = detect_node_scripts(dir).await;
        return ProjectInfo {
            name,
            language_summary: "JavaScript / Node.js".into(),
            build_cmd: build,
            test_cmd: test,
            top_level_dirs: scan_top_dirs(dir).await,
        };
    }
    if dir.join("pyproject.toml").exists() || dir.join("setup.py").exists() {
        return ProjectInfo {
            name: dir_name(dir),
            language_summary: "Python".into(),
            build_cmd: Some("pip install -e .".into()),
            test_cmd: Some("pytest".into()),
            top_level_dirs: scan_top_dirs(dir).await,
        };
    }
    if dir.join("go.mod").exists() {
        return ProjectInfo {
            name: dir_name(dir),
            language_summary: "Go".into(),
            build_cmd: Some("go build ./...".into()),
            test_cmd: Some("go test ./...".into()),
            top_level_dirs: scan_top_dirs(dir).await,
        };
    }
    ProjectInfo {
        name: dir_name(dir),
        language_summary: "(unknown)".into(),
        build_cmd: None,
        test_cmd: None,
        top_level_dirs: scan_top_dirs(dir).await,
    }
}
```

```
async fn parse_cargo_name(dir: &std::path::Path) -> Option<String> {
    let content = fs::read_to_string(dir.join("Cargo.toml")).await.ok()?;
    for line in content.lines() {
        let trimmed = line.trim();
        if let Some(rest) = trimmed.strip_prefix("name") {
            if let Some(val) = rest.trim().strip_prefix('=') {
                return Some(val.trim().trim_matches('"').to_string());
            }
        }
    }
    None
}

async fn detect_node_scripts(dir: &std::path::Path) -> (Option<String>, Option<String>) {
    let content = match fs::read_to_string(dir.join("package.json")).await {
        Ok(c) => c,
        Err(_) => return (None, None),
    };
    let build = if content.contains("\"build\"") {
        Some("npm run build".into())
    } else {
        None
    };
    let test = if content.contains("\"test\"") {
        Some("npm test".into())
    } else {
        None
    };
    (build, test)
}

async fn scan_top_dirs(dir: &std::path::Path) -> Vec<String> {
    let mut dirs = Vec::new();
    let skip = ["target", "node_modules", ".git", "__pycache__", ".cache", "dist", "build"];
    if let Ok(mut rd) = tokio::fs::read_dir(dir).await {
        while let Ok(Some(entry)) = rd.next_entry().await {
            let name = entry.file_name();
            let name_str = name.to_string_lossy();
            if entry.path().is_dir()
                && !name_str.starts_with('.')
                && !skip.contains(&name_str.as_ref())
            {
                dirs.push(name_str.into_owned());
            }
        }
    }
    dirs.sort();
    dirs
}

fn dir_name(dir: &std::path::Path) -> String {
    dir.file_name()
        .and_then(|n| n.to_str())
        .unwrap_or("project")
        .to_string()
}
```

## 8. Acceptance Criteria

1. **AC-1: Root load** — When `AGENTS.md` exists at `working_dir`, it is loaded
   before the first agent turn and a `Message::system(...)` containing its
   content appears at the front of `prior_messages`.

2. **AC-2: No file, no injection** — When `AGENTS.md` does not exist, no
   `Message::system` is prepended and no error or warning is emitted beyond
   a `TRACE`-level log.

3. **AC-3: Size cap** — A 100 KB `AGENTS.md` is read, truncated at exactly
   `agents_md_max_bytes` bytes at a valid UTF-8 boundary, and the string
   `[AGENTS.md truncated at 64 KB]` appears at the end of the injected content.

4. **AC-4: Signal emission** — `XaftAgentsMdLoaded` is emitted after a
   successful load with the correct `paths` and `total_bytes`. The signal
   is NOT emitted when no file was found.

5. **AC-5: TUI status line** — After loading, the TUI transcript displays
   a `[agents.md]` system line showing the file name and byte count.

6. **AC-6: Mid-session hook** — When the planner calls `list_files` and the
   result includes `backend/AGENTS.md`, the hook auto-reads the file and a
   `Message::user(...)` with `"source": "agents_md_auto_load"` metadata is
   injected before the next LLM turn.

7. **AC-7: Multiple files** — If `list_files` returns both `AGENTS.md` and
   `services/api/AGENTS.md`, both are read and injected as separate messages,
   root-first order.

8. **AC-8: Root-first ordering** — When injecting multiple AGENTS.md files,
   files with fewer path segments appear before files with more (i.e.,
   `AGENTS.md` before `a/AGENTS.md` before `a/b/AGENTS.md`).

9. **AC-9: Config disable** — When `core.agents_md_enabled = false`, no
   AGENTS.md file is loaded at session start and the `AgentsMdPostHook` is
   not registered.

10. **AC-10: `/init` generates file** — Running `/init` in a Rust/Cargo
    workspace creates a valid `AGENTS.md` with correct `Build:` and `Test:`
    lines and all template sections present.

11. **AC-11: `/init --force` overwrites** — Running `/init --force` overwrites
    an existing `AGENTS.md` without prompting.

12. **AC-12: `/init` no-overwrite guard** — Running `/init` when `AGENTS.md`
    exists (without `--force`) returns a message saying the file already
    exists and instructs the user to use `--force`.

13. **AC-13: prior_messages ordering** — The system message injected by
    `AgentsMdLoader` is always the first element of `prior_messages`. Any
    conversation history from session resume follows it.

14. **AC-14: Hook does not double-inject** — Loading the root `AGENTS.md` at
    session start does NOT cause it to be re-injected when the planner calls
    `list_files` and the root `AGENTS.md` appears in the results. The session-
    start load uses `Message::system`; the hook produces `Message::user`.
    Both can coexist and are distinguishable by role.

### 9.4 `test_utf8_boundary_preserved`

**What it tests:** When the truncation point falls inside a multi-byte UTF-8
character, `find_utf8_boundary` backs up to the previous valid boundary so
the output is valid UTF-8.

```rust
#[test]
fn test_utf8_boundary_preserved() {
    // "é" = 0xC3 0xA9 (2 bytes). Truncate at boundary mid-character.
    let s = "aé";
    let bytes = s.as_bytes(); // [97, 195, 169]
    // Truncate at 2 (inside the 'é')
    let boundary = find_utf8_boundary(&bytes[..2]);
    assert_eq!(boundary, 1); // should back up to before 0xC3
    let result = std::str::from_utf8(&bytes[..boundary]);
    assert!(result.is_ok());
}
```

## 10. Migration & Rollout

1. The feature ships behind `core.agents_md_enabled = true` (default on).
   Operators who need to suppress loading in CI can set
   `XAFT_AGENTS_MD_ENABLED=false`.
2. No database migrations required — the feature is stateless (file reads
   only).
3. The `AgentsMdLoader` is additive: it never modifies `AGENTS.md` and never
   writes to the session store beyond the in-memory `prior_messages`.
4. The `ToolHook` addition requires `run_workflow()` signature change
   (`extra_hooks` parameter). This is a semver-compatible addition since
   `run_workflow` is not a public API surface; all callers are in
   `xaft-runtime`.

## 11. Open Questions

1. **De-duplication strategy for mid-session injection**: If the planner
   calls `list_files` multiple times in one session and `AGENTS.md` appears
   each time, the context grows with each injection. Options:
   - Track injected paths in the hook and skip already-seen ones. (preferred)
   - Rely on natural context compression (compaction, PRD 36/50).
   - Document the current behaviour in a known-limitations note.

2. **AGENTS.md in git-ignored directories**: If the workspace `.gitignore`
   excludes `AGENTS.md` (unusual but possible), xaft still loads it since
   `AgentsMdLoader` reads from the filesystem directly, not via the git index.
   No action needed; document as intentional.

3. **Priority between AGENTS.md and session-injected system prompts**:
   When a session has both a custom system prompt (from `AgentPreset`) and
   an AGENTS.md injection, the AGENTS.md content appears in `prior_messages`
   while the custom prompt is the true system prompt. The planner sees both.
   No conflict is expected but integration tests should verify ordering.
